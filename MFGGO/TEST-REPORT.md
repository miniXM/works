## 构建结果

`npm run build` 已成功生成 Vite 生产构建产物。

Vite 输出了部分 chunk 超过 500 kB 的优化提示，但不影响构建成功或当前功能验收。后续可通过动态导入和 `manualChunks` 做性能优化。

## 浏览器人工点击验收

> 验收方式：使用 Codex 内置浏览器按真实用户路径操作，不调用页面内部函数绕过 UI。  
> 前端页面：`http://127.0.0.1:7410/enterprise.html`  
> API：`http://127.0.0.1:4310`

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 登录失败提示 | 输入 `admin` / 错误密码并点击“登录” | 通过：页面显示“账号或密码不正确” |
| 登录成功 | 输入本地账号 `admin` / `123456` 并点击“登录” | 通过：进入企业工作台，显示完整导航 |
| 聊天信息 | 点击“聊天信息” | 通过：显示会话列表、未读筛选、企业/项目筛选、消息输入框和发送按钮 |
| 项目沟通空状态 | 点击“项目沟通” | 通过：显示空状态和“发起沟通”入口 |
| 发起沟通弹窗 | 点击“发起沟通” | 通过：弹出关联项目、沟通主题、第一条消息表单及取消/提交按钮 |
| 项目管理 | 点击“项目管理” | 通过：显示项目看板和项目卡片 |
| 根任务详情 | 点击项目卡片“浏览器附件验收” | 通过：直接打开该项目唯一根任务的详情弹窗，显示字段、参与者、动态、评论和附件区 |
| 子任务详情 | 在项目根任务中点击子任务“000” | 通过：打开嵌套任务详情，显示“返回上级”和 `【AAAA】 › AAAA › 000` 面包屑 |
| 子任务复选框 | 打开根任务与子任务详情后检查子任务区 | 通过：没有 `.task-subtask-check`、没有 `data-subtask-toggle`，页面也没有 `☑` 残留 |

| 控制台错误 | 完成上述操作后读取浏览器错误日志 | 通过：未发现 error/warning 日志 |
