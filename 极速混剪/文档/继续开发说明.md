# 极速VideoMix 迁移说明

## 当前可发布文件
- `最新发布/JSVideoMix-Setup-1.0.3.exe`：完整安装包
- `最新发布/update-client-1.0.3.zip`：更新包
- `最新发布/VideoMix-LicenseServer.exe`：旧的本地授权服务工具，仅作历史交付物保留

## 客户端继续修改
进入 `客户端重建/work/rebrand`。
- `skin/vm-skin.css`：界面皮肤
- `skin/vm-theme.js`：主题和顶部/侧栏行为
- `brand.json`：品牌和版本配置
- `base/`：构建所需基础资源
- `build/out/`：最近一次构建产物

构建顺序：先运行 `make_rules.py`，再运行 `build_asar.py`，最后运行 `patch_integrity.py`。

## PHP 授权后台
宝塔上传 `授权后台PHP/部署` 目录内容，按 `授权后台PHP/部署-宝塔PHP版.md` 配置站点和数据库。

本备份不包含 Python 授权后台、旧测试数据、旧版本包和临时测试文件。
