# 1.0.3 发布记录（2026-09-20）

## 这一版改了什么

只改了一件对客户有影响的事：**安装包里内置的默认授权服务器地址**，
从已经废弃的 `http://8.130.70.64:8082`（旧 Python 后台）改成
正式域名 **`https://hj.jisuai.cc`**（新的 PHP 网站后台）。

顺带把版本号从 1.0.2 提到 1.0.3。界面、功能、图标、品牌文字都没动，
`videomix/resources/app.asar` 和 `videomix\videomix.exe` 与 1.0.2 逐字节相同。

## 为什么必须重新出包

安装包把默认授权地址编译进了 `VideoMix.exe`（启动器）里的
`Generated.DefaultServerUrl` 常量，这个常量来自
`work\videomix-rebuild\default-server.txt`：

```powershell
# 改完 default-server.txt 必须重跑，地址才会进到 exe 里
pwsh -File .\build-launcher.ps1 -PackInstaller
```

旧地址指向的机器上，Python 后台已经被删掉了，客户装完连不上、激活不了。

## 怎么发

新客户：发 `JSVideoMix-Setup-1.0.3.exe`，双击安装，安装完客户端默认连
`https://hj.jisuai.cc`。

> 装过 1.0.2 的机器**不用重装**，但默认地址是错的（指向废弃 IP）。
> 两种办法二选一：
> 1. 直接重装 1.0.3（最省事，客户还没发出去时推荐这个）；
> 2. 在客户端里手动把授权服务器地址改成 `https://hj.jisuai.cc`。

已经装过 1.0.2 且地址已经是对的客户，走在线升级：

1. 登录授权后台 → **客户端升级** → 版本号填 `1.0.3` → 选 `update-client-1.0.3.zip` → 发布更新
2. 客户下次打开客户端时会自动下载并重启

> 更新包里放的是 `VideoMix.exe`（启动器）和 `videomix\resources\app.asar`，
> 和 1.0.2 那次一样。

## 验证过什么

- **安装包端到端**（`work\videomix-rebuild\run-e2e2.ps1 -WithUninstall`）：23/23 通过
  静默装 → 客户端启动 → 本机代理激活成功 → 换设备被拒 `E2` → 同设备重复激活 `SC`
  → 定期复核 `SC` → 静默卸载清干净
- **装出来的文件跟 payload 逐字节一致**：`app.asar`、`videomix.exe` 两个指纹都对上
- **新 payload 的完整性**：和上一版 payload 逐条目比对，
  1720 个条目名字和长度全一致，只有 `VideoMix.exe` 的 CRC 变了（就是要改它）
- **启动器里确实换了地址**：UTF-16 扫描 exe 字符串，
  有 `https://hj.jisuai.cc`、没有 `8.130.70.64`、有 `1.0.3`

## 怎么复现这一版

```powershell
cd "E:\GPT Codex\2026-09-15\new-chat\work\videomix-rebuild"
# default-server.txt 里写 https://hj.jisuai.cc，client-version.txt 里写 1.0.3

```
